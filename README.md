# HR Analytics Dashboard

An interactive Human Resources analytics dashboard built with Tableau Public to analyze employee retention, headcount distribution, and key workforce metrics.

🔗 [View Interactive Dashboard on Tableau Public](https://public.tableau.com/views/HRDashboard_17934043997690/HRSummary)



## 📌 Project Overview
This project provides data-driven insights into organization-wide HR performance. The primary objective is to help decision-makers monitor employee demographics, identify attrition trends, and optimize retention strategies across departments.



## 📊 Key Features & Metrics
* **Headcount Summary:** Total active workforce broken down by department, role, and employment type.
* **Attrition Analysis:** Tracking turnover rates across tenure groups and job roles to pinpoint high-risk retention areas.
* **Demographic Breakdown:** Visualizations covering age distribution, gender balance, and department diversity.
* **Interactive Filtering:** Drill down by specific departments, date ranges, or employee status directly on the view.
